# Yadhu Rajan — Portfolio

Animated telecom, fibre-network and project-delivery portfolio.

## Publish with GitHub Pages

1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, set **Source** to **GitHub Actions**.
3. Open the **Actions** tab and check the **Publish portfolio to GitHub Pages** workflow.
4. Once the workflow succeeds, open:

   https://thriloksolo-tech.github.io/yadhu-Portfolio/

**Repository visibility:** GitHub Free requires the source repository to be public for Pages. GitHub Pro, Team and Enterprise plans can publish from private repositories. The published website itself is public on the internet, even when the source repository is private.

The workflow reconstructs `public/index.html` from the compressed static-site parts in `.site/` and deploys it as a Pages artifact.
